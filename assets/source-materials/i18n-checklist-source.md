# 国际化设计 Checklist
> 适用于车队 IoT SaaS 平台（Vue + Element Plus），覆盖中文、蒙古语、英语等多语言场景。

---

## 一、字段文案

| 规则 | 说明 | ❌ 反例 | ✅ 正例 |
|---|---|---|---|
| field-note ≤ 6 个汉字 | 超出翻译后大概率断行或溢出 | 建议设为 1–5L，避免数据频繁跳动 | 建议 1–5L |
| 选项文字 ≤ 4 个汉字 | radio / checkbox / tag 容器宽度有限 | 满箱时阻值较高 | 正装 |
| section 标题 ≤ 6 个汉字 | 避免标题换行 | 传感器量程 — 填写铭牌上的数值范围 | 传感器量程 |
| 按钮文字 ≤ 4 个汉字 | 按钮宽度固定，长文本会截断 | 添加所选配件 | 添加所选 |
| 表头 ≤ 5 个汉字 | 表头宽度影响整列宽度 | 蓝牙配对状态 | 配件状态 |
| tooltip 不限长度 | tooltip 宽度自适应，可放详细解释 | — | 任意长度 |

---

## 二、数值与单位

| 规则 | 说明 | ❌ 反例 | ✅ 正例 |
|---|---|---|---|
| 单位用国际通用符号 | 避免用中文单位名称 | 升 | L |
| 单位符号写在 unit slot 里 | 不要拼在字段值里 | 300升 | 300（单位列：L）|
| 数字格式不做硬编码 | 千分位、小数点不同语言习惯不同，交给 i18n 库处理 | `1,024.5` 写死 | `Intl.NumberFormat` |
| 日期时间用 ISO 格式传输 | 显示层由前端 locale 控制 | 2026年5月24日 写死 | `2026-05-24T00:00:00Z` |

---

## 三、布局与空间

| 规则 | 说明 |
|---|---|
| 文本容器预留 1.5x 空间 | 中文翻译成英语通常会变长 30–50%，翻译成蒙古语可能增加 2 倍 |
| 避免固定宽度的文本容器 | 用 `min-width` + `max-width` 代替 `width` 固定值 |
| 选项卡（tab）使用 flex 均分或自适应 | 不要固定每个 tab 的像素宽度 |
| 面包屑和标题栏允许换行 | 不要用 `white-space: nowrap` 截断标题 |
| 表格列宽用 `minmax` | 让内容列自适应，避免文字溢出变成省略号 |
| 弹窗宽度设 `max-width: 96vw` | 避免在小屏或窄视口下溢出 |

---

## 四、图标与视觉

| 规则 | 说明 | ❌ 反例 | ✅ 正例 |
|---|---|---|---|
| 图标不单独承载状态语义 | 颜色盲用户无法区分颜色，图标形状需同时传递信息 | 只用红/绿色区分状态 | 红色 ⊗ / 绿色 ⊙ |
| 避免图标内嵌文字 | 文字图标无法翻译 | 把「正」「反」写在图标里 | 图标 + 旁边文字标签 |
| 文字方向 ltr/rtl | 如果需要支持阿拉伯语，整体布局需翻转 | — | 使用 CSS `direction` / `logical properties` |

---

## 五、交互文案

| 位置 | 规则 | 说明 |
|---|---|---|
| Toast 提示 | ≤ 16 个汉字 | Toast 宽度有限，长文本换行后被截断 |
| 确认弹窗正文 | 可适当长，但每句话不超过 30 字 | 弹窗宽度固定约 420px，翻译后需能放下 |
| 空态引导文字 | 分两行：主标题 ≤ 8 字，副文案 ≤ 16 字 | 两行结构比一行长文案更易翻译 |
| 报错文案 | 避免使用比喻、俚语 | 「数据跑丢了」→ 「暂无数据」 |
| 操作成功提示 | 用「已 + 动词」结构 | 「保存成功」→「已保存」（英文 Saved） |

## 六、硬编码排查清单

上线前检查以下内容是否有硬编码中文：

- [ ] 所有 `placeholder` 属性
- [ ] 所有 `title` / `aria-label` 属性
- [ ] 所有 `data-tip` tooltip 内容
- [ ] 所有 Toast / showToast 调用
- [ ] 所有确认弹窗的 `confirmText.textContent`
- [ ] 所有空态（empty state）的提示文字
- [ ] 所有 `field-note` 内容
- [ ] 所有报警 / 错误提示文案
- [ ] 表格列头文字
- [ ] 导航菜单文字

---

## 七、快速判断：这段文案需要改吗？

```
文案超过 6 个汉字？
  └── 是 → 在 field-note / 按钮 / 选项里？
             └── 是 → 必须精简或拆分
             └── 否（在 tooltip / 弹窗正文里）→ 可以保留，确认容器能自适应宽度
  └── 否 → 通过 ✓
```

## 八、本项目已落实的案例

| 场景 | 改前 | 改后 | 原则 |
|---|---|---|---|
| 油量传感器安装方向 | 满箱时阻值较高 / 满箱时阻值较低 | 正装 / 反装 | 选项 ≤ 4 字 |
| 读数校准 section 标题 | 传感器量程 — 填写铭牌上标注的数值范围 | 传感器量程 | section 标题 ≤ 6 字 |
| 读数波动提示 | 建议设为 1–5L，避免数据频繁跳动 | 建议 1–5L（详情移入 tooltip） | field-note ≤ 6 字 |
| 开门报警范围提示 | 建议 5–30 min，范围 1–120 min | 建议 5–30 min（范围移入 tooltip） | field-note ≤ 6 字 |
| 温湿度配件数量说明 | S5L 最多可添加 5 个温湿度标签；标签 ID 解绑后保留 | 最多添加 5 个配件（其余移入 tooltip） | 副标题精简 |
| 监控时段选项 | 全天监控（24 小时持续）| 全天监控 + 副文案「24 小时持续」 | 主标签 ≤ 4 字，细节用副文案 |
