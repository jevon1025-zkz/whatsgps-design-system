# WhatsGPS Design System Skill 3.0

Codex skill for WhatsGPS / Justrack / 立即定位 PC hardware-device operations platform design, implementation, documentation, and review work.

## 3.0 Scope

- PC navigation and top-bar optimization.
- Permission-aware global search and related query logic.
- Alarm and in-system reminder copy shared by PC and mobile.
- PC function-menu and role-permission context.
- Device-icon creation and display rules, Figma source constraints, direction-frame specification, and device-detail optimization.
- Design tokens, field copy, internationalization, and UI quality checks.

APP feature design, APP information-architecture redesign, and the complete 68-alarm taxonomy are intentionally out of scope. The Skill records device-icon rules but does not bundle the historical 150-PNG icon library.
